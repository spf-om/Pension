# حاسبة التأمينات والحماية الاجتماعية

داشبورد تفاعلي (ملف HTML واحد بدون اعتمادات) محوّل من ملف الإكسل «الحاسبة للنظام الجديد».

## التبويبات
- منفعة كبار السن
- المعاش التقاعدي (النظام الجديد)
- العجز والوفاة
- مكافأة فقد المعاش
- ضم الخدمة
- النظام السابق (خاص / حكومي / ديوان)

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو انشره عبر GitHub Pages
(Settings ثم Pages ثم Branch: main ثم / root).

الحسابات استرشادية.
